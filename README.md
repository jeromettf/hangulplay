# 한글 쏙쏙! 포켓몬스터 대도감 & 배틀 스타디움

아이들이 포켓몬과 함께 한글을 익히는 가족용 웹 앱이에요. 파일 하나(`index.html`)로 동작해요.

- 포켓몬 도감, 한글 쓰기, 퀴즈, 색칠놀이
- 그림 동화책 · 참여 동화
- 수학 놀이 (3~7세, 세기부터 시계·돈 계산까지 7단계)
- 그림 찾기: 숨은그림찾기, 틀린그림찾기, 조각·밀기 퍼즐 (3~7세)
- 스티커 10개마다 포켓몬 카드, 카드 앨범
- 배틀 스타디움 (컴퓨터 · 2인 · 관장/챔피언)

배틀 엔진: [Pokémon Showdown](https://github.com/smogon/pokemon-showdown) 시뮬레이터 (MIT License).
포켓몬 이름·그림 등은 각 권리자의 것이며, 이 앱은 가족끼리 쓰는 비상업용이에요.
